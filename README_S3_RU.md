# Эта ветка больше не главная

Поддерживаемая линия — отдельный репозиторий [FGMDCharge-S3](https://github.com/pomsfgend/FGMDCharge-S3), версия 3.0.0. Она снята с куба **2.8.17** ([FGMDCharge-FD-ROUND-V2](https://github.com/pomsfgend/FGMDCharge-FD-ROUND-V2)), не с 2.8.15. Ноги те же, что уже записаны в `main/boards/esp32s3_devkit.h` на этой ветке. Старую таблицу из README куба (подсветка 14, тач 8/9, реле 15/16) не использовать. Текст ниже оставлен, чтобы ссылка на ветку не вела в пустоту.

# FD_ROUND S3 — ветка hw/esp32-s3

Исходник `src/2.8.15` (ESP32-C3, куб) переложен на **ESP32-S3-DevKitC-1**.
Прошивка по-прежнему контроллер: экран, тач, Wi-Fi, CAN GB/T 27930, два логических реле.
Силовую станцию эта ветка не заменяет.

Старый куб этой веткой не шить. Ему остаётся `src/2.8.15` и `GO.bat` с чипом `esp32c3`.

Полная карта, цены и провод в провод: `docs/s3/PORT_RU.md`.
Виртуальный сеанс с теми же шагами автомата собран отдельно и не шьётся в чип.

## Что меняется в коде

Пины больше не зашиты в `main/config.h`. Их задаёт профиль:

- `main/boards/esp32s3_devkit.h` — по умолчанию
- `main/boards/esp32c3_cube.h` — старые ноги, только если специально собирать C3

`display.c` версии 2.8.15 уже умеет ST7789 и ILI9341 через `CUBE_LCD_USE_ST7789`.
Другие контроллеры в этом коммите не инициализируются: драйверы открытые, но это следующий патч.

Таблица разделов не сдвинута. Лог сессии по-прежнему с `0x330000`.
На новом модуле 16 МБ это просто хвост пустой флеш.

## Сборка

Нужен уже стоящий ESP-IDF **5.0.9**, тот же, что собирал куб.

```
idf.py set-target esp32s3
idf.py build
```

Пустую плату шить целиком, не слотом ota_1 куба:

```
esptool --chip esp32s3 -p COM* -b 460800 write_flash ^
  0x0 build/bootloader/bootloader.bin ^
  0x8000 build/partition_table/partition-table.bin ^
  0x10000 build/FGMDCharge_FD_ROUND_V2.bin
```

Имя бинарника оставить как в CMake, чтобы не плодить второй артефакт. В логе будет `READY 3.0.0`.

Точка: `Cube` / `12345678`, сайт `http://192.168.4.1/`.
