# original/

Backup slices of the cube as it shipped, including `dump1.bin` (4 MiB).

This is not source code. The MIT license of the repository does not apply here.
The new firmware uses these bytes only so the boot menu can still start the factory image in `ota_0`.

If you publish the sources, you can omit this directory. Cable flash of both slots (`GO.bat`) needs these files. OTA of `release/FGMDCharge_FD_ROUND_V2.bin` does not.
