FGMDCharge FD_ROUND V2 — 2.3.0
================================

Что нового
----------
1. Web UI: подключен /style.css (раньше стили не грузились — в HTML не было link).
2. Адаптивный интерфейс для телефона и ПК.
3. Дисплей: яркость (SYS, слайдер 5–100%), при CPU >75°C яркость ↓40%.
4. Температура CPU в °C, частота, load, heap.
5. Клавиатура WiFi: кнопка «Скрыть KB», скрытие по OK/Cancel.
6. Тач: быстрее (I2C timeout 12 ms, LVGL 10 ms / tick 5 ms).
7. SoftAP: SSID Cube / пароль 123456789, канал 6.

Температура ~80°C
-----------------
- Снизь яркость на SYS.
- Не держи куб в закрытом корпусе без вентиляции.
- USB-UART иногда даёт слабое питание — внешние 5V предпочтительнее.
- Wi‑Fi SoftAP греет чип — это нормально для C3 под нагрузкой.

Сборка
------
1. (желательно) ERASE_PHY_NVS.bat если был
2. BUILD_RELEASE.bat
3. FLASH_RELEASE_OTA1.bat → COM
4. Телефон: Cube / 123456789 → http://192.168.4.1/

Когда web + WiFi стабильны — модернизация GB/T state machine и протоколов.
