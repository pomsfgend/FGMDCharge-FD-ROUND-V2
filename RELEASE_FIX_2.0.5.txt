FGMDCharge / FD_ROUND V2 — Release 2.0.5
=======================================

Changes from 2.0.4:
1) Fixed nested-comment compile error in web_assets.c (/* inside /*).
2) Size optimization so the app fits into the original OTA slot 0x190000:
   - CONFIG_COMPILER_OPTIMIZATION_SIZE=y
   - reduced log level
   - aggressively disabled unused LVGL widgets/features (only obj+label+2 fonts needed)
   - reduced WiFi/LWIP/HTTPD buffers
   - trimmed some Bluedroid options that are not required for advertising+GATTS
3) force_sdkconfig.py updated accordingly.
4) Version bumped to 2.0.5.

Binary must stay <= 0x190000 (1638400 bytes) to match the original partition layout
used by FLASH_RELEASE_OTA1.bat (writes only the app image into the existing OTA1 slot).
