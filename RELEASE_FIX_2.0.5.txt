FGMDCharge / FD_ROUND V2 — Release 2.0.5
=======================================

Build fixes:
1) Nested comment in web_assets.c fixed.
2) Version strings unified to 2.0.5 (static_audit / verify_release).
3) BUILD_RELEASE.bat rewritten: always shows output, always pauses on error,
   rejects paths with spaces, CRLF line endings. START_BUILD.cmd added.
4) LVGL config: CONFIG_LV_USE_IMG=y (required by animimg headers) and
   CONFIG_LV_USE_ANIMIMG=n. Previous over-aggressive widget disable broke
   the LVGL dependency chain.
5) Size optimization kept (COMPILER_OPTIMIZATION_SIZE, reduced buffers).

Binary must stay <= 0x190000 to match original OTA slot layout.
