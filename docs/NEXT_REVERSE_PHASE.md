# Следующий этап реверса

1. С реального кубика получить USB boot log новой/старой прошивки.
2. Снять `flash-id` и `get_security_info`.
3. Подтвердить touch ChipID 0xA7 и координаты.
4. Снять CAN passive capture во время реального сеанса зарядки.
5. Сравнить кадры с recovered IDs и внутренними полями старой прошивки.
6. Восстановить точное поведение CML/CCS и длинных TP-сообщений.
7. Снять BLE trace: запись в FFE1/FFE2/FFE3, CCCD, OTA sequence.
8. После этого добавить точную совместимость со старым мобильным приложением.
