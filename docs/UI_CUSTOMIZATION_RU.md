# Как менять внешний вид

## TFT

Вся экранная сцена находится в `main/display.c` в функции `ui_create()`.

Меняются напрямую:

- фон `lv_color_hex(...)`;
- тексты `lv_label_set_text(...)`;
- положение `lv_obj_align(...)`;
- размеры карточек `lv_obj_set_size(...)`;
- цвета и рамки через `lv_obj_set_style_*`.

Для картинки-фона лучше добавить ресурс как RGB565 или использовать LVGL image descriptor. Не патчить старую картинку в BIN.

## Web

Файлы:

```text
main/web/index.html
main/web/style.css
main/web/app.js
```

Они вшиваются прямо в flash приложения, поэтому отдельный файловый раздел LittleFS/SPIFFS не нужен.

## CAN

Файл `main/can_gbt.c` — единственная точка доступа к TWAI. Все новые сообщения сначала добавляйте как RX-only и проверяйте на пассивной шине.

Для реального управления зарядником только после тестов разрешайте `tx_enabled`.
