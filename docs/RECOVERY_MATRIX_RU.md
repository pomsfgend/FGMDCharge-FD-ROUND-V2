# Матрица восстановления

| Что | Состояние | Что делать |
|---|---|---|
| Полный исходный flash | восстановим | `restore_full_dump.py` |
| Bootloader | сохранён | не менять на первом тесте |
| Partition table | сохранена | совпадает с оригиналом |
| OTA0 | сохраняется | используется как откат |
| OTA1 | место для V2 | сюда ставится первая тестовая app |
| NVS | не изменяется при первом app flash | сохраняется |
| LCD | восстановлен | GPIO 5/19/4/18, 20 MHz |
| CAN RX | восстановлен | GPIO 10/9, 250 kbit/s |
| CAN TX | реализован, но OFF | включать только после проверки |
| BLE GATT | воспроизведён | FFE0 / FFE1/FFE2/FFE3 |
| Web UI | новый | Wi-Fi AP + HTTP |
| Web OTA | новый | запись в неактивный OTA slot |
| Touch | высокая уверенность | runtime ChipID; ориентацию тестировать |
| ADC/PWM | не до конца доказаны | V2 не управляет неизвестными GPIO |
| Исходники производителя | не восстановимы буквально | реверс даёт заменяющую реализацию |
